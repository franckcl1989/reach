# Reach 0.1.1 release evidence

Version 0.1.1 is a presentation-only release. The diagnostic state machines,
probe order, deadlines, capability boundaries, aggregation, and exit meanings
remain the 0.1.0 design. A source comparison from the published 0.1.0 tag
commit (`3455e5e1b341eb2c8b613aca82f23dbbb78f5ce6`) to the 0.1.1 release-gate
commit found no changes under `crates/reach-core/src` or
`crates/reach-platform/src`.

compiler version or toolchain file is pinned.

## Output-contract evidence

The automated tests cover every input-error and execution-error kind, all
completed conclusion labels, cancellation, output routing, terminal-safe
untrusted text, redirected ANSI behavior, help, version, invalid command
shapes, TCP success and refusal, and complete plain-text error snapshots.

Manual release-binary checks additionally exercised these user-visible
archetypes:

- successful hostname resolution and ICMP replies from multiple addresses;
- TCP timeouts accompanied by independent ICMP replies;
- a nonexistent hostname;
- ICMP silence with an explicitly inconclusive conclusion;
- invalid address and port input;
- successful loopback TCP, explicit TCP refusal, and cancellation.

The reports put a plain-language verdict, check summary, every destination,
meaning, and cautious next step before the support detail. They retain ordered
resolver records, every network Attempt and timing limit, relevant path and
Neighbor facts, capability limitations, platform, version, and exit code. The
scope boundaries in `docs/0.1.1-output-contract.md` prevent TCP, ICMP, timeout,
and refusal observations from being overstated.
