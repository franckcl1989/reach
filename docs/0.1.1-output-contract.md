# Reach 0.1.1 presentation note (historical)

This file records the presentation policy shipped in version 0.1.1. It is not
a current product contract and must not be used to override the root design
baseline.

Version 0.1.1 attempted to serve end users and support engineers in one default
report by appending all Attempts and technical facts. That choice conflicted
with section 21.1 of `network-diagnostic-cli-design.md`, which requires a concise
conclusion plus only the minimum Key Evidence selected by Core and explicitly
forbids expanding every Attempt, route, Neighbor state, path hop, or internal
step by default.

Starting with version 0.1.2, the root design is again the sole normative
default-output contract. The diagnostic state machines, traffic, deadlines,
capability boundaries, aggregation, exit meanings, and complete typed internal
evidence remain unchanged; only the default projection is reduced to the
designed minimum.

The stdout/stderr, cancellation, terminal-safety, and plain-language behavior
that did not conflict with the root design remains governed by that root design
and its tests.
